Path Vector Routing Algorithm Simulator

This simulator demonstrates Path Vector Routing, which is the basis for BGP (Border Gateway Protocol) used for inter-AS routing on the Internet. Unlike distance vector and link state protocols, path vector protocols maintain the entire path to each destination and use policy-based routing decisions.

In this simulation, we have multiple Autonomous Systems (AS) exchanging routing information for various network prefixes (destinations). Each AS applies local policies like shortest AS path, customer preference, and loop prevention.
