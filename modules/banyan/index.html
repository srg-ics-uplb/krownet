About Banyan Networks

A Banyan network is a multistage interconnection network (MIN) with the self-routing property. Each stage consists of 2×2 switching elements that route packets based on the destination address bits.

Key characteristics of Banyan networks:

  • For N inputs/outputs, the network has log₂N stages
  • Each stage has N/2 switching elements
  • Packets are routed based on their destination address bits
  • Collisions occur when two packets attempt to use the same link simultaneously
