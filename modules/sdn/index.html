Control Plane ⓘ

The Control Plane in SDN architecture is responsible for making forwarding decisions and programming the data plane. This plane:

  • Maintains a global network view
  • Makes traffic engineering decisions
  • Programs forwarding rules to switches
  • Communicates with switches using the OpenFlow protocol
  • Enables programmable network management

Data Plane ⓘ

The Data Plane in SDN architecture is responsible for forwarding packets based on rules received from the controller. This plane:

  • Consists of physical or virtual switches
  • Forwards packets according to flow table entries
  • Communicates with the controller when unknown flows are encountered
  • Has no intelligence about network-wide decisions
  • Performs fast forwarding based on pre-programmed rules
