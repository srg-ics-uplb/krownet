KROWNET - a collection of simulations and visualizations for data communications and computer networking concepts

Overview

This is an old project that has been recently revived because of the advancements in GenAI which allows faster creation of simulation and visualization. Modules only use HTML 5,CSS, and Javascript for easier deployment and can thus be run locally.

Modules

  • Periodic Composite Signals
  • Non-Periodic Composite Signals
  • Digital Signal as Composite Analog Signals
  • Baseband Digital Transmission
  • Attenuation
  • Distortion
  • Bandwidth-Delay Product
  • Line Coding Techniques
  • Multilevel Encoding: 2B1Q
  • Delays in Packet-Switched Networks
  • Time Division Multiplexing
  • Digital to Analog Conversion
  • Quadrature Amplitude Modulation
  • Frequency Modulation
  • Frequency Hopping Spread Spectrum
  • Direct Sequence Spread Spectrum
  • Banyan Switch
