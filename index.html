KROWNET - a collection of simulations and visualizations for data communications and computer networking concepts

Overview

This is an old project that has been recently revived because of the advancements in GenAI which allows faster creation of simulation and visualization. Modules only use HTML 5,CSS, and Javascript for easier deployment and can thus be run locally.
