KROWNET - a collection of visualizations for data communications and computer networking concepts

Overview

This is an old project that has been recently revived because of the advancements in GenAI which allows faster creation of simulation and visualization tools. Modules only use HTML 5,CSS, and Javascript for easier deployment and can thus be run locally.

Modules

  • IP Address Calculations
  • Signals
  • Line Coding Techniques
  • Delays in Packet-Switched Networks
  • Time Division Multiplexing
  • Digital to Analog Conversion
  • Quadrature Amplitude Modulation
  • Frequency Modulation
